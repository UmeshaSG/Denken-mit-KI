# Denken mit KI

Blog: https://umeshasg.github.io/denken-mit-ki/

## Einen neuen Beitrag hinzufügen

1. Öffne den Ordner [`_posts`](_posts) auf GitHub (geht auch in der GitHub-App).
2. Tippe auf **Add file → Create new file**.
3. Dateiname: `JJJJ-MM-TT-titel.md`, z. B. `2026-11-21-mein-gedanke.md`.
   Datum und `.md` am Ende sind Pflicht, sonst erscheint der Beitrag nicht.
4. Kopiere den Kopf aus [`POST_TEMPLATE.md`](POST_TEMPLATE.md), ändere Titel und Datum, schreib darunter deinen Text.
5. **Commit changes** auf `main`. Nach etwa 1 bis 2 Minuten ist der Beitrag online.

Beitrag ändern oder löschen: Datei in `_posts` öffnen und bearbeiten (Stift-Symbol) oder löschen.
